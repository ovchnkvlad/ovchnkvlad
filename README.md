## Engineering principles

- Automate repeatable work and keep the manual recovery path documented.
- Use least privilege and secure defaults.
- Treat secrets, state files, and build artifacts as sensitive data.
- Test infrastructure code before deployment.
- Prefer observable systems and evidence-backed troubleshooting.
